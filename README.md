# Joshua Wesley Obaigwa — Portfolio

A responsive React + CSS portfolio for Data Analytics and Data Engineering.

## Requirements
- Node.js (LTS recommended)
- npm

## Run locally
1. Extract this ZIP.
2. Open the extracted `joshua-wesley-portfolio` folder in VS Code.
3. Open a terminal in that folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Before publishing
Update these items in `src/App.jsx`:
- Replace `your.email@example.com` with your real email address.
- Replace the generic GitHub and LinkedIn links with your own profile URLs.
- Add GitHub repository URLs to each project when the projects are published.
- Review the skills list and remove any tools you have not used yet.
- Update project status labels as work progresses.
- Add a CV file and a resume download button when your CV is ready.

## Build for production
```bash
npm run build
npm run preview
```

## Notes
- Project cards intentionally label planned or in-progress work honestly.
- Google Fonts are loaded from the web; the site still has fallback fonts if they are unavailable.
